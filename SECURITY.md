# Security Policy

## Supported Versions

Kamio is currently in beta. Security fixes are applied to the latest
release line only.

| Version   | Supported |
|-----------|-----------|
| 1.0.0bx   | Latest beta only |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security reports.

Instead, report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/Peim0n/kamio/security/advisories/new)
or by email to d.sytnikov@int-sys.ru.

Please include:

- a description of the vulnerability and its impact,
- steps to reproduce or a proof of concept,
- the affected version(s).

We aim to acknowledge reports within a few days and will coordinate a
fix and disclosure timeline with you.
